# Password Cracking and Recovery Lab

## Overview

This repository documents my hands-on practical experience with password cracking and recovery using **John the Ripper (JTR)** and **NetworkWalks Password Cracking Tools**.

The exercise introduced me to password hash extraction, hash-based password recovery, and wordlist-based password attacks in a controlled learning environment.

---

## Learning Objectives

- Understand how password hashes are extracted from password-protected PDF files.
- Gain practical experience using John the Ripper.
- Explore graphical password recovery using Johnny.
- Understand wordlist-based password recovery.
- Appreciate the importance of strong and unique passwords.

---

## Module 1: Password Cracking with John the Ripper (JTR)

**Tool:** John the Ripper (JTR)
**Interface:** Johnny (GUI)

### Activities Performed

- Worked with John the Ripper through its graphical interface, Johnny.
- Extracted password hashes from password-protected PDF files.
- Loaded the extracted hashes into the password recovery tool.
- Performed password recovery attacks.
- Successfully recovered the passwords of all three provided PDF files.

## Module 2: Password Cracking with NetworkWalks Tools

### Activities Performed

- Used the NetworkWalks Hash Calculator to extract a PDF password hash.
- Submitted the extracted hash to the Password Cracker tool.
- Observed the wordlist-based password recovery process.

## Key Learning Outcomes

This practical exercise helped me understand:

- How password hashes are extracted from protected PDF documents.
- How password recovery tools work with extracted hashes.
- How wordlists are used to identify weak passwords.
- The relationship between password complexity and password security.

---

## Key Takeaway

Strong and unique passwords remain an essential part of personal and organisational cybersecurity.

## Conclusion

This exercise was an important step in moving from theoretical cybersecurity knowledge to practical application.

Working with two different approaches to password recovery gave me a better appreciation of how password security can be tested and why organisations must encourage strong password practices.

I look forward to building on this experience through more hands-on cybersecurity labs.
